Behavior Landscape Guided LLM For Policy Search
Prompted Policy Search:
Use LLM as optimzer to find optimal policy $\theta^*$ which minimize $J(\theta) = E[r]$. By providing task description and search history at each iteration $H_t = {(\theta_i, J(\theta_i): 1 <= i <= t}$, LLM will decide which policy to search next. We can consider this as sequential decision making.
Our Proposal:
Existing Gap: Existing RL (include Gradient Policy method and ProPS) relies solely on reward signals, which may be uninformative in sparse-reward environments (like Mountain Car…)
We can use VLM as the trajectory analyzer. By passing into VLM frames of a trajectory, VLM will feedback by the behavior description of the policy. Furthermore, we just not only use VLM only 1 policy but also its neighbor, by adding to its dimension random small number. Totally, the iteration looklike, we have 3 anchor: best, worst and current policy. We will describe the bahavior of policy and its neighbor by using VLM, then pass them into LLM to optimze.
Full Pseudocode:
$\textbf{Training Loop} \
\text{for } t = 1,\dots,N_{episodes} \
{\theta_{cur},\theta_{best},\theta_{worst}} \
\text{are selected as anchors.} \
\text{For each anchor } \theta_a: \
\tau_a, F_a = \text{Rollout}(E,\theta_a) \
analysis_a = VLM(F_a, D, \theta_a) \
\text{Sample neighbors} \
\theta_j = \theta_a + \Delta_j \
\text{and analyze them with VLM.} \
\text{Construct neighborhood summary} \
\Psi_t \
\text{LLM proposes next policy} \
\theta_{t+1} = LLM(\Gamma, P, \Psi_t, D) \
\text{Evaluate policy} \
r_{t+1} = \text{Evaluate}(E,\theta_{t+1})$
