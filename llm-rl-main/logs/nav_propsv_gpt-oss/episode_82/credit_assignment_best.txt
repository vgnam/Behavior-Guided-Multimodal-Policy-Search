High‑reward rollouts consistently keep a steady forward action for long stretches (often > 200 timesteps) and only introduce turns or minor corrective actions after the state has progressed smoothly, whereas low‑reward rollouts insert abrupt action switches—especially rapid accelerations or sharp turns—within a few timesteps, causing sudden spikes in the state value and loss of control. The successful trajectories also show a pattern of delaying large directional changes until the agent has built momentum, using brief, low‑amplitude corrections (single‑step actions 1 or 2) rather than prolonged bursts of action 0 that dominate the failing episodes. Moreover, high‑reward episodes avoid early spikes above a state threshold (≈ 2.5) and instead maintain the state in a moderate range before gradually climbing, while low‑reward runs often overshoot this range early and then crash. This disciplined pacing prevents collisions and keeps the agent within the navigable corridor, directly translating into higher cumulative reward.
