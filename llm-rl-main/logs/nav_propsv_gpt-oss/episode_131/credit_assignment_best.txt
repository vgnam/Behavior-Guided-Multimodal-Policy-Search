High‑reward rollouts repeatedly interleave a dominant forward‑thrust action (action 0) with brief, well‑timed corrective turns (actions 1 or 2) whenever the state value drifts beyond a narrow band, keeping the agent’s trajectory centered and preventing long excursions; in contrast, low‑reward rollouts either sustain a single action for many steps (e.g., continuous forward thrust or unchecked turning) or apply corrections too late, allowing the state to wander far from the optimal corridor. The successful runs also exhibit early stabilization, showing a quick reduction of the initial state value within the first few timesteps, whereas the poor runs start with large state values that only later decline—or never do—leading to collisions or failures. Moreover, high‑reward episodes tend to avoid prolonged periods of the same corrective action, instead alternating between left and right turns to fine‑tune the path, while low‑reward episodes display monotonic drift in one direction, reflecting a lack of responsive steering. These patterns plausibly boost reward because they maintain the agent within the narrow, reward‑rich region of the maze and prevent the costly wall contacts that dominate the low‑reward trajectories.
