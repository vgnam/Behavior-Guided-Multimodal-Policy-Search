The high‑reward rollouts tend to exhibit gradual, sustained actions that change the state only modestly from one frame to the next, often repeating the same control (e.g., repeatedly selecting action 0) and allowing several timesteps of forward motion before any termination occurs. In contrast, the low‑reward rollouts feature abrupt, large‑magnitude actions—sometimes a single decisive move such as action 2—that produce a drastic jump in the state vector and end the episode within one or two frames. This smoother pacing in the better runs lets the agent stay away from walls long enough to collect positive intermediate rewards, whereas the rapid, aggressive thrusts in the poorer runs cause immediate collisions and large negative penalties. Consequently, the presence of incremental state evolution and prolonged, consistent action selection correlates with higher returns, while sudden state shifts and premature termination correlate with the lowest returns.
