The high‑reward rollouts all contain at least one early change in the chosen action – the agent briefly turns or adjusts its heading after the first step instead of repeating the same command, producing a short, directed drift away from the start before the episode ends. In contrast, the low‑reward rollouts never deviate from the constant “action 2” signal, so the state value merely oscillates within a narrow band and the agent never creates a purposeful trajectory. This occasional turn in the better rollouts prevents the agent from getting trapped in the repetitive, bounded oscillation that accrues the maximal –500 penalty, thereby limiting the number of timesteps over which negative reward is collected. Because the worse rollouts maintain a single, unvarying action, they generate larger, erratic swings and stay alive longer, compounding the per‑step penalty and yielding the most negative scores.
