The high‑reward rollouts all contain brief periods where the agent deliberately changes direction or slows down—often by following a wall or pausing near the corridor edge—whereas the low‑reward rollouts persist with the same forward‑thrust action (action 2) throughout the episode. This intermittent turning or speed‑reduction keeps the trajectory smooth and prevents the agent from hitting a boundary, while the constant‑action sequences produce large, erratic jumps in the state value that quickly lead to collisions. Moreover, the better rollouts tend to start with a modest forward push and then adjust their heading, whereas the worst rollouts launch immediately into an aggressive thrust and never correct the overshoot. By introducing these corrective actions and timing them before the state diverges, the agent maintains a more stable path and thus avoids the severe penalties that dominate the low‑reward trajectories.
