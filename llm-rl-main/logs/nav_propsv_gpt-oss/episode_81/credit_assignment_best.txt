High‑reward rollouts repeatedly interleave short bursts of the forward‑thrust action (action 0) with frequent, modest corrective actions (actions 1 or 2) throughout the episode, keeping the state value within a narrow band and never allowing a long uninterrupted straight run; by contrast, low‑reward rollouts either sustain a single forward action for many steps or execute a single sharp turn late in the episode, which drives the state value outside the safe corridor and produces large negative rewards. The successful trajectories also exhibit early‑stage oscillations that continually realign the agent with the corridor walls, whereas the failing runs show a delayed or missing re‑alignment, letting the agent drift into a boundary before a sudden, high‑impact correction. Moreover, the best rollouts avoid any abrupt, high‑magnitude actions after the midpoint, maintaining smooth, incremental adjustments, while the poor rollouts contain a late, abrupt turn (often action 0 used as a sharp change) that precipitates a crash. This pattern of continuous, low‑amplitude corrections prevents collisions and sustains positive reward accumulation, explaining the stark performance gap.
