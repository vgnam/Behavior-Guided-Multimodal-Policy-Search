The high‑reward rollouts all contain a brief, purposeful deviation from the default forward thrust (action 2) – usually a single “0” (stop/turn) applied after a few hundred steps that abruptly reduces the state value and prevents the agent from drifting into the far wall, whereas the low‑reward rollouts never use action 0 and remain at action 2 for the entire episode. In the better runs this corrective action is timed just before the state value begins a runaway increase, creating a short stabilising dip that limits the later overshoot; the worst runs show a monotonic rise in the state value with no such dip. Moreover, the higher‑reward trajectories display an early phase of relatively smooth, monotonic growth (steady forward motion) followed by a controlled correction, while the low‑reward trajectories are dominated from the start by large, erratic swings in the state value with no clear transition to a steadier regime. This combination of an initial stable push and a timely corrective stop curtails the excessive oscillations that otherwise accumulate large negative rewards, explaining why the occasional “0” and its proper placement yield noticeably better returns.
