**1. SUCCESS PATTERNS** – The rollouts that earned the highest rewards all exhibit **a steady, low‑amplitude forward thrust that begins in the first few frames and is maintained throughout the episode**.  The agent makes only **small, gradual steering adjustments** when a wall is approached, never executing a sudden 90° turn or a large acceleration spike.  This smooth, continuous motion keeps the state variable changing by < 0.2 per step, which lets the agent stay inside the corridor and collect the incremental positive rewards for distance traveled.  Because the trajectory stays controllable, the episode rarely ends in a “fail” tag, allowing the cumulative reward to grow large.

**2. FAILURE PATTERNS** – The low‑reward rollouts share **aggressive, high‑magnitude actions that cause abrupt state jumps (often > 1.0 in a single step)**, usually right after the first action.  These spikes are coupled with **rapid, hard turns or thrusts into tight corners**, producing oscillations or overshoot that quickly bring the agent into a wall.  The resulting collisions generate a large negative reward and terminate the episode almost immediately, so the agent never accrues the positive distance reward.  A secondary but common element is a **persistent drift without corrective steering**, which leaves the agent heading straight into the boundary.

**3. DISCRIMINATIVE PATTERNS** –  
1. **Continuous low‑amplitude forward thrust** (present in 4/5 high‑reward rollouts, 0/5 low‑reward) – the most decisive cue of success.  
2. **Absence of large instantaneous state jumps** (> 1.0) (absent in all high‑reward, present in 4/5 low‑reward) – a clear failure indicator.  
3. **Gradual, small‑angle steering corrections** (seen in 4/5 high‑reward, only vague in 1/5 low‑reward) – reinforces stable navigation.  

The optimizer should **strongly reinforce pattern 1**, **moderately reinforce pattern 3**, and **suppress pattern 2**.

**4. TIMING** – All three discriminative patterns manifest **early in the episode (within the first 2–3 steps)** and persist thereafter.  The smooth thrust and lack of big jumps are established at the very start, setting the trajectory that determines success.  Controlled turning appears slightly later, typically when the first wall is encountered, but still well before any failure events, indicating it is causal rather than merely correlative.
